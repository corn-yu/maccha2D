MODスイッチ  v1.0.0
==================

Mod Menu の MOD 一覧から、MOD をオン・オフできるようにする MOD です。
Minecraft Java 26.3 ＋ Fabric（Fabric API と Mod Menu も入れてください）。

■ つかいかた
  1. タイトル画面か ポーズ画面の「Mods」ボタンで Mod Menu を開く
  2. 下の右がわの「MODスイッチ」ボタンを押す
  3. mods フォルダの MOD が並ぶので、押すたびに ● オン / ○ オフ が切りかわる
  4. Minecraft を再起動すると反映されます（「(再起動で)」がついているのが 変えた MOD）

■ しくみ
  ・オフにすると、mods フォルダの jar の名前のうしろに .disabled がつきます（Fabric は読みません）
    オンにもどすと .disabled がとれます。ファイルは消えません
  ・Windows では動いている MOD の jar は名前を変えられないので、
    Minecraft を閉じたあとに 自動で名前を変えます（少しだけ PowerShell が見えないところで動きます）
  ・MODスイッチ自身はオフにできません。もどすときは mods フォルダで .disabled を消してください
  ・Fabric API をオフにすると ほとんどの MOD が動かなくなるので気をつけてね
  ・オフにした MOD は Mod Menu の一覧には出ませんが、MODスイッチの画面には出ます
