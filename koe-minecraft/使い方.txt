こえマイクラ（声だけで操作するマインクラフト）v0.2.0 試作

■ これは何？
マイクに話した言葉で、マイクラのキャラを動かす MOD です。
「まえ」で歩き、「ほって」でブロックをこわし、「ジャンプ」でとびます。
言葉を文字にするのは Vosk（ボスク）という音声認識で、ぜんぶ自分のパソコンの中で動きます。
インターネットにお金はかかりません（はじめの1回だけ、日本語モデル約48MBを自動でダウンロードします）。

■ いるもの
- Minecraft Java 26.3 ＋ Fabric Loader（0.19.3 より新しいもの）＋ Fabric API
- マイク（ヘッドホンがおすすめ。スピーカーの音や友だちの声を拾うと、かってに動きます）
- Windows の設定 → プライバシー → マイク →「デスクトップ アプリがマイクにアクセスできるようにする」をオン

■ 入れかた
1. koemine-0.2.0.jar を mods フォルダに入れる（Fabric API と同じところ）
2. マイクラを起動して、ワールドに入る
3. チャットに「日本語モデルをダウンロード中…」と出て、しばらくすると
   「聞いています！」と出たら準備OK
   ※ ダウンロードできないときは、ブラウザで
     https://alphacephei.com/vosk/models/vosk-model-small-ja-0.22.zip
     をダウンロードして、展開した中のフォルダを
     （マイクラのフォルダ）\config\koemine\model
     という名前で置いてください。

■ 言える言葉（最初の設定）
歩く      まえ / すすめ / あるいて / はしれ / うしろ / さがって / 一歩前 / ちょっと前 / 一歩後ろ
          左によけて / 右へよけて
とまる    とまれ / ストップ / 待って（「ぜんぶやめて」で掘る・たおすも止める）
ジャンプ  ジャンプ / とんで / 連続ジャンプ / 泳いで / 登って / オートジャンプ（オン・オフ）
しゃがむ  しゃがんで / 立って / 降りて（馬やボートから）/ 乗って
むき      右 / 左（90度）、ちょっと右 / ちょっと左（30度）、うしろむいて
          上 / 下 / 上を見て / 下を見て / もっと上（30度ずつ）、ちょっと上 / ちょっと下、
          まっすぐ、真上、真下、視点（カメラ切りかえ）
こわす    ほって / こわして（おしっぱなし。とまれでやめる）、下を掘って、トンネル
こうげき  こうげき / なぐって（1回）、連打、敵をたおして、ねらって（近くの敵を見る）
つかう    置いて / 使って / 開けて / 寝て（右クリック）、食べて（食べ物を持って食べる）、飲んで
          引いて → 撃って（弓）、守って（盾）、持ちかえ（左手と入れかえ）
もちもの  インベントリ、閉じて、捨てて、1番〜9番、次、剣 / つるはし / 斧 / シャベル / 弓 / 松明 / ブロック / 食べ物
足もと    足元に置いて / 上に登って（真下を見てジャンプして置く）
チェスト  全部入れて / 全部取って / できたの取って（作業台・かまどの できあがり）
そのほか  リスポーン / 生き返って、ポーズ
マイク    マイクオフ / 聞かないで（お休み）→ マイクオン（もどる）
言葉表    ことばよみこみ（ことば.txt を読みなおす）

■ 名前で言う（〇〇はアイテム・ブロック・モブの名前ならなんでも）
〇〇つくって   レシピ本を使ってクラフト（例: 作業台つくって、松明つくって、鉄のつるはしつくって）
               2x2 で作れないものは、近く（4ブロック）の作業台を自動で開いて作ります
               まだおぼえていないレシピは作れません（材料を一度手に入れると おぼえます）
〇〇焼いて     近くのかまどを開いて焼きます（例: 鉄インゴット焼いて）。できたら「できたの取って」
〇〇を持って   持ち物の中から手に持つ（例: 石の剣を持って、パンを持って）
〇〇を見て     近くの〇〇の方を向く（例: 木を見て、作業台を見て、ゾンビを見て）
〇〇を掘って   近くの〇〇を向いて、こわれるまで掘る（例: 木を切って、鉄を掘って、石炭を掘って）
〇〇をたおして 近くの〇〇に近づいて、こわれるまで攻撃（例: ゾンビをたおして、牛をたおして）

■ 言葉を変えたい
（マイクラのフォルダ）\config\koemine\ことば.txt をメモ帳で開いて、
「言葉 = アクション」を書きたしてください。書いたら、ゲームの中で「ことばよみこみ」と言います。
例:  すすめー = forward
     ためて = hold_use
     木こり = name:mine|木        （「木こり」で 木を切る）
     *けいこうせき = iron_ore     （あだ名。「けいこうせきを掘って」で鉄鉱石）
はじめは「ことばだけ聞く = はい」で、表の言葉とアイテムの名前だけを聞きます（速くて正確）。
何でも聞きとってほしいときは「!ことばだけ聞く = いいえ」にします。
v0.1 の ことば.txt は ことば-old.txt という名前で残してあります。

■ 友だちと遊ぶとき（Essential など）
この MOD は自分のパソコンの中だけで動きます。サーバーや相手には何も入れなくていいです。
声で動かしたい人だけが、自分の mods に入れてください。
友だちとしゃべるときは「マイクオフ」と言うと、そのあいだは動きません。「マイクオン」でもどります。

■ うまく聞きとれないとき
- 少しはっきり、短く言う（「まえ」「ほって」）
- まわりを静かにする、マイクの音量を上げる
- 言葉が文字になるのは、言い終わって少ししてからのことがあります
- 記録は（マイクラのフォルダ）\logs\latest.log に「こえマイクラ:」で出ます
