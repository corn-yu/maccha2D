こえマイクラ（声だけで操作するマインクラフト）v0.2.8 試作

■ これは何？
マイクに話した言葉で、マイクラのキャラを動かす MOD です。
「まえ」で歩き、「壊して」でブロックをこわし、「ジャンプ」でとびます。
言葉を文字にするのは Vosk（ボスク）という音声認識で、ぜんぶ自分のパソコンの中で動きます。
インターネットにお金はかかりません（はじめの1回だけ、日本語モデル約48MBを自動でダウンロードします）。

■ いるもの
- Minecraft Java 26.3 ＋ Fabric Loader（0.19.3 より新しいもの）＋ Fabric API
- マイク（ヘッドホンがおすすめ。スピーカーの音や友だちの声を拾うと、かってに動きます）
- Windows の設定 → プライバシー → マイク →「デスクトップ アプリがマイクにアクセスできるようにする」をオン

■ 入れかた
1. koemine-0.2.8.jar を mods フォルダに入れる（Fabric API と同じところ）
2. マイクラを起動して、ワールドに入る
3. チャットに「日本語モデルをダウンロード中…」と出て、しばらくすると
   「聞いています！」と出たら準備OK
   ※ ダウンロードできないときは、ブラウザで
     https://alphacephei.com/vosk/models/vosk-model-small-ja-0.22.zip
     をダウンロードして、展開した中のフォルダを
     （マイクラのフォルダ）\config\koemine\model
     という名前で置いてください。

■ 言える言葉（最初の設定）
歩く      まえ / すすめ / あるいて / はしれ / うしろ / さがって / 一歩前 / ちょっと前 / 一歩後ろ
          左によけて / 右へよけて
とまる    とまれ / ストップ / 待って（「ぜんぶやめて」で壊すのも止める）
ジャンプ  ジャンプ / とんで / 連続ジャンプ / 泳いで / 登って / オートジャンプ（オン・オフ）
しゃがむ  しゃがんで / 立って / 降りて（馬やボートから）/ 乗って
むき      右 / 左（90度）、ちょっと右 / ちょっと左（30度）、うしろむいて
          上 / 下 / 上を見て / 下を見て / もっと上（30度ずつ）、ちょっと上 / ちょっと下、
          まっすぐ、真上、真下、視点（カメラ切りかえ）
こわす    壊して（今向いているブロックを、とまれまで おしっぱなし）、下を壊して
          どこを壊すかは、自分で「右」「上」などで向いて決めます
こうげき  こうげき / なぐって（1回）、連打（0.5秒ごと）。モブの方を向くのも近づくのも自分で
つかう    置いて / 使って / 開けて / 寝て（右クリック）、食べて（食べ物を持って食べる）、飲んで
          引いて → 撃って（弓）、守って（盾）、持ちかえ（左手と入れかえ）
もちもの  インベントリ（開いているときに言うと閉じる）、閉じて、捨てて、1番〜9番、次、剣 / つるはし / 斧 / シャベル / 弓 / 松明 / ブロック / 食べ物
くみあわせ ジャンプして置いて（とんで いちばん高いところで置く）
          ジャンプして攻撃 / ジャンプして殴って（とんで 落ちはじめたところで攻撃＝クリティカル）
足もと    足元に置いて / 上に登って（真下を見てジャンプして置く）
チェスト  全部入れて / 全部取って / できたの取って（作業台・かまどの できあがり）
そのほか  リスポーン / 生き返って、ポーズ
マイク    マイクオフ / 聞かないで（お休み）→ マイクオン（もどる）
言葉表    ことばよみこみ（ことば.txt を読みなおす）

■ 長い動き（詠唱）
ブリッジのような「ひと言でいくつもする言葉」は入れていません。自分で順番に言います。
例: ブリッジ  →「しゃがんで」「うしろ」「真下」…「置いて」「置いて」「置いて」…「とまれ」
    言った順に、聞きとれたものから すぐに動きます。早く・正確に言えるほど うまくなります。

■ チャットで発動モード（声のかわりに、チャットに打って動かす）
/koemine chat on   … オン（次に起動したときも オンのまま）
/koemine chat off  … オフ
/koemine chat      … オンとオフを入れかえる
オンのとき、チャットに「まえ」「しゃがんで うしろ 置いて 置いて とまれ」などと打つと、
声と同じ言葉表（ことば.txt）で、前から順に動きます（言葉と言葉のあいだは0.2秒）。
言葉が入っていたチャットは、みんなには送られません。言葉がひとつも入っていないチャットは ふつうに送られます。
マイクオフのときでも、チャットからは動きます。
誤変換や打ちまちがいも、読みで自動でカバーします:
  「老いて」→ 置いて、「舞え」→ まえ、「じゃんぴ」→ ジャンプ、「いんべんとい」→ インベントリ
  「止まる」→ とまれ、「こわす」「壊せ」→ 壊して、「進め」→ まえ（動詞の形がちがうだけなら同じ言葉）
  （読みが同じ言葉はそのまま、読みが1文字ちがう言葉まで。長い言葉は2文字ちがいまで）
  似た意味の言葉も入っています（停止・まて → とまれ、ほれ・掘って・破壊 → 壊して、前進・いけ → まえ、後退 → うしろ、叩け・斬れ → 攻撃 など）
  それでも足りない言葉は、ことば.txt に書きたしてください（例: にげて = sprint）
言葉でない所が多いチャット（「前回のボス強かった」など）は、ふつうのおしゃべりとして送られます。

■ 名前で言う（〇〇はアイテムの名前ならなんでも）
〇〇つくって   レシピ本を使ってクラフト（例: 作業台つくって、松明つくって、鉄のつるはしつくって）
               2x2 で作れるものは、どこでも作れます
               3x3 がいるものは、作業台の前で「開けて」と言って開いてから言います
               まだおぼえていないレシピは作れません（材料を一度手に入れると おぼえます）
〇〇焼いて     かまどの前で「開けて」と言って開いてから言います（例: 鉄インゴット焼いて）。できたら「できたの取って」
〇〇を持って   持ち物の中から手に持つ（例: 石の剣を持って、パンを持って）

■ 言葉を変えたい
（マイクラのフォルダ）\config\koemine\ことば.txt をメモ帳で開いて、
「言葉 = アクション」を書きたしてください。書いたら、ゲームの中で「ことばよみこみ」と言います。
例:  すすめー = forward
     ためて = hold_use
     ほれ = dig                   （「ほれ」で壊す）
     *いもの = potato             （あだ名。「いものを持って」でジャガイモ）
はじめは「ことばだけ聞く = はい」で、表の言葉とアイテムの名前だけを聞きます（速くて正確）。
何でも聞きとってほしいときは「!ことばだけ聞く = いいえ」にします。
新しい版を入れても、自分で書いた行は消えません（新しい言葉が下に足されるだけ）。
前の版の ことば.txt は ことば-old.txt という名前で残してあります。
自分で「ひと言でいくつもする言葉」を作りたいときは + でつなぎます（wait:10 は 0.5秒まつ）。
例:  ためうち = hold_use+wait:20+release_use

■ アクション名の一覧（ことば.txt の右がわに書くもの）
うごく   forward（まえ）walk（あるく）back（うしろ）sprint（はしる）stop（とまる）stop_all（ぜんぶやめる）
         strafe_left / strafe_right（よける）step_forward / short_forward / step_back（すこしだけ）

■ 友だちと遊ぶとき（Essential など）
この MOD は自分のパソコンの中だけで動きます。サーバーや相手には何も入れなくていいです。
声で動かしたい人だけが、自分の mods に入れてください。
友だちとしゃべるときは「マイクオフ」と言うと、そのあいだは動きません。「マイクオン」でもどります。

■ うまく聞きとれないとき
- 少しはっきり、短く言う（「まえ」「壊して」）
- まわりを静かにする、マイクの音量を上げる
- 言葉が文字になるのは、言い終わって少ししてからのことがあります
- 記録は（マイクラのフォルダ）\logs\latest.log に「こえマイクラ:」で出ます
