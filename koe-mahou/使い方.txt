こえまほう（声の詠唱で魔法）  v0.6.0
=====================================

マイクに向かって呪文を1行ずつ詠唱すると、魔法が出る MOD です。
Minecraft Java 26.3 ＋ Fabric（Fabric API も入れてください）。

■ 入れかた
  mods フォルダに koemahou-0.6.0.jar を入れます。
  Essential で友だちと遊ぶときは、全員とワールドの持ち主が入れてください。
  （魔法の効果はワールドの持ち主のほうで出すので、持ち主に入っていないと魔法が出ません）

  ※ こえマイクラ（koemine）と いっしょに入れると、マイクを2つの MOD が同時に聞きます。
    まずは どちらか片方で遊ぶのがおすすめです。
  ※ 日本語の音声モデルは、こえマイクラのものがあれば それを使います。
    なければ、はじめの1回だけ ダウンロードします（約48MB）。

■ 魔導書で魔法を覚える
  ・はじめは何も唱えられません。魔導書を右クリックで読むと、その魔法を覚えます
  ・宝箱（ダンジョン・廃坑・神殿・村の教会・要塞・森の洋館・古代都市・沈没船など）に
    ときどき「謎の魔導書」が入っています。読むと、まだ覚えていない魔法を1つ覚えます
  ・コマンドでも出せます（チートが必要）
      /koemahou 魔導書 <魔法の名前>   … その魔法の魔導書
      /koemahou 謎の魔導書           … 謎の魔導書
  ・覚えた魔法は「魔法本」にのります。はじめて覚えたときにもらえます
      /koemahou 魔法本               … 魔法本をもう1冊（だれでも使えます）
  ・宝箱に謎の魔導書を入れるかどうかは、コマンドで変えられます（チートが必要）
      /koemahou 宝箱                 … いまの設定を見る
      /koemahou 宝箱 オフ            … 宝箱に入れない
      /koemahou 宝箱 オン            … 入れる（30%、はじめの設定）
      /koemahou 宝箱 <0〜100>        … 入る確率を％で決める
    設定はワールドごとです。まだ開けていない宝箱から効きます
  ・覚えたことは ワールドごと・人ごとに とっておかれます
  ・魔法の中身は ワールドの持ち主の じゅもん.txt です。友だちは じゅもん.txt がなくても、
    魔導書を読めば同じ魔法が使えます。持ち主が じゅもん.txt を書きかえると、すぐみんなに反映されます

■ チャットで唱える（チャットモード）
  ・/まほうチャット オン  … チャットに詠唱を打つと、声と同じように魔法が進みます
    /まほうチャット オフ  … もとにもどす（/まほうチャット だけでも切りかわります）
  ・1行ずつ送っても、全部の行を1回にまとめて送ってもOK（空白や「、」で区切ってもOK）
  ・詠唱が入っているチャットは、みんなには出ません。詠唱でないチャットはふつうに出ます
  ・チャットモードのときは、行と行のあいだを20秒まで待ちます
  ・チャットモードでも声で唱えられます。設定は自分のパソコンにとっておかれます

■ あそびかた
  ・呪文は何行かの詠唱です。1行言うごとに、画面の下の ◇ が ◆ になります
  ・全部の行を順番に言いきると、魔法が出ます
  ・6秒だまったり、順番をまちがえたりすると「詠唱失敗」（けむりが出るだけ）
  ・詠唱しているあいだも、自分で歩いたり にげたりできます
  ・魔法ごとに、つぎに使えるまでの待ち時間があります

■ 魔法は自分で作る
  呪文（詠唱）も効果も、まっちゃが自分で作ります。
  ・「魔法パズル」の画面でピースをつなげる
  ・または config/koemahou/じゅもん.txt をメモ帳で書く
  くわしくは「魔法の作りかた.txt」を見てね。
